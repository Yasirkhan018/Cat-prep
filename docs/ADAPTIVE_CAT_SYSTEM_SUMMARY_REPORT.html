2. Architectural Highlights

A. 12-Question Diagnostic Assessment

  • VARC (4 Questions): Evaluates main idea extraction, argument weakening, sentence sequence (TITA), and paragraph summary.
  • DILR (4 Questions): Tests linear arrangement constraints, multi-attribute matrix matching, set theory inclusion-exclusion (TITA), and quarterly revenue tables.
  • QA (4 Questions): Benchmarks profit markup multipliers, work efficiency rates (TITA), quadratic discriminant roots, and right-triangle incircles.

B. Adaptive Persona Differentiation

  • Beginner Track: Promotes foundational arithmetic and reading skills. Step-by-step 4-phase learning journey (Learn → Example → Guided Try → 10 Practice Qs). Mocks and full PYQ papers are discreetly deprioritized to avoid cognitive overload.
  • Intermediate Track: Focuses on moderate-level problem sets, pacing targets, weak-area drills, and selective past-year CAT slot questions.
  • Advanced Track: Prioritizes full 120-minute slot simulations, high-complexity DILR matrix sets, and negative marking elimination strategies.
  • Flow & Persona Switcher: A dedicated toolbar at the bottom of the home screen allows instantaneous switching between Beginner, Intermediate, Advanced, and Diagnostic Reset.

C. Intelligent Practice Engine & Solution Quality

  • TITA Answer Normalizer: Correctly recognizes equivalent mathematical forms such as sequences (3421 vs 3-4-2-1), formatted currency (₹4000 vs 4000), decimals (2.5 vs 2.50), and fractions (5/2).
  • Pedagogical Multi-step Solutions: Eliminates terse one-line answers. Every question provides the formula, underlying theoretical explanation, common student pitfalls, and speed heuristics.
